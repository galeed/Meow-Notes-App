# 🤝 Contribuir a Meow Notes App

¡Gracias por tu interés en mejorar Meow Notes! 🐱 Este documento explica cómo reportar bugs, proponer ideas y enviar código.

---

## 📋 Antes de empezar

- Revisa si ya existe un [issue](../../issues) o [PR](../../pulls) para lo que quieres hacer.
- Para cambios grandes (nuevas features, refactors), abre primero un **issue** para discutirlo. Evita PRs sorpresa de 2000 líneas.
- Para cambios pequeños (typos, estilos, un bug claro), puedes ir directo al PR.

---

## 🐛 Reportar un bug

Usa la plantilla de **Bug report** al abrir un issue. Incluye:

1. **Pasos para reproducir** — numerados y concretos.
2. **Comportamiento esperado** vs. **comportamiento actual**.
3. **Navegador y versión** (Chrome 120, Safari 17, Firefox 121…).
4. **Sistema operativo** (Windows 11, macOS 14, Android 14…).
5. Si aplica: **captura de pantalla** o mensaje de la consola (DevTools → Console).
6. Si aplica: si ocurre **online/offline** o con la app **instalada/sin instalar**.
